# Aptelum Studio examples

Six public, fictional website designs for feedback. [Industries](https://asbillings07.github.io/aptelum-studio-examples/) groups [Wellness](https://asbillings07.github.io/aptelum-studio-examples/industries/wellness/) and [Technology](https://asbillings07.github.io/aptelum-studio-examples/industries/technology/). These are marketing design examples, not operating practices, products or services.

Forma Aesthetics emphasizes choosing a provider, Vale Skin Studio understanding skin-care options, and Morrow Wellness & Body Care a welcoming first step. Each has a concise homepage, distinct service explanations, provider/approach and consultation pages. Editorial rows, soft galleries and alternating care paths give them different identities. Relevant local imagery and bounded portraits support readable layouts. Complimentary initial consultations are illustrative offers for these examples; treatments and further clinical assessments are separate. Real client offers require individual confirmation.

Threadline demonstrates workflow software, Northstar IT managed services, and Vector Harbor developer infrastructure. Each has five content pages plus privacy. Every Technology page offers **Appearance → System / Light / Dark**. System follows the device and removes the saved override. Light or Dark saves one browser-only preference shared across all six Wellness and Technology examples; no preference is sent to a server. If storage is blocked, switching still works on the current page. A small, integrity-pinned local script manages this preference; the page and system palette remain usable without JavaScript.

Navigation, image/product disclosures, menus and FAQs use native controls. Vale requests remain unavailable; its old flat URLs remain compatible. Forma/Morrow booking actions explain the example. Technology enquiries cannot be submitted. No forms, accounts, analytics, advertising, remote fonts, patient data, product backend or real booking integration. The appearance choice is the only site-created browser storage. Forma, Vale and Morrow offer the same System / Light / Dark choice with distinct brand palettes. The original preference key is retained so returning visitors keep their choice.

Images and assets are served from this repository. Generated people and product illustrations are fictional; no invented metrics, credentials, testimonials, certifications or measured conversion results are presented as real evidence. GitHub Pages hosts the files and maintains its own security logs; see each site's privacy link. Noindex is a feedback preference, not privacy or access control. Unknown routes use the shared404, while Vale's404 can also be inspected directly. Its sitemap is only a route inventory; no search submission is made.

The Studio gallery uses its approved folded-ribbon logo, a quiet solid-blue Aptelum attribution and relevant human imagery. The gallery remains light; the six client examples retain their own Light/Dark/System controls. Vale service images sit alongside text at wider widths and stack on phones.

Only public example assets and their minimal build/check tooling belong here; private company records and real customer data stay outside this repository. Vercel serves only the explicit public inventory built into `dist/`. These designs do not establish clinical/client approval, accessibility conformance, production readiness or exclusive rights to names/assets. Aptelum Studio pricing remains provisional.

GitHub Pages publishes the root of `main`; a push changes the public examples. Keep Pages available while reviewing the Vercel replacement. No custom domain is connected to Pages. Production will use Vercel after separate approval; `aptelumstudio.com` remains reserved for that launch.

The [Vercel preview setup and launch gates](docs/vercel-preview.md) preserve the approved site while adapting its URLs and hosting disclosure in the generated output. Run `node scripts/build-preview.mjs` to build and `python3 -m unittest discover -s tests -v` to verify. The build refuses production, and Vercel Git deployment is disabled for `main`. No production promotion, DNS change or Pages retirement is included. Actual preview setup and review evidence belong to the PR; configuration files alone do not prove deployment.
