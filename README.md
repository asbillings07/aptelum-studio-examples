# Aptelum Studio examples

Three public design examples for feedback: Forma Aesthetics, Vale Skin Studio, and Morrow Wellness & Body Care. These are fictional practices with generated imagery. They do not offer appointments or clinical services. Complimentary initial consultations are an illustrative offer chosen for these examples, not a claim about every medspa or finalized Aptelum Studio pricing; real client offers must be confirmed individually.

Open [Industries](https://asbillings07.github.io/aptelum-studio-examples/) to explore the [Wellness examples](https://asbillings07.github.io/aptelum-studio-examples/industries/wellness/) and a [Technology direction preview](https://asbillings07.github.io/aptelum-studio-examples/industries/technology/). The three existing practice URLs (`forma/`, `vale/`, `morrow/`) remain usable. Technology is a visual direction, not a fourth complete example or an available product.

Each example contains seven content pages with ordinary links and native menus. Short homepages introduce the business; service pages provide fuller explanations. Relevant skin, consultation and wellness imagery, bounded provider portraits, varied spacing and native expandable image panels support the browsing flow. The image panels work by click, tap or keyboard; no essential information depends on hovering. Vale's consultation/location page honestly shows requests as unavailable, and its previous flat page URLs remain usable. Forma and Morrow retain their existing booking-preview disclosures. No JavaScript, forms, browser storage, analytics, external fonts, patient data or real booking integration. All imagery is served from this repository. GitHub Pages handles hosting and its own security logs; see each site's privacy link.

Vale's assets and navigation are scoped under `vale/` for this GitHub Pages project path. Its static privacy page describes the current GitHub host. Unknown URLs continue to use the shared gallery's existing root `404.html`; `vale/404.html` is also available to inspect the Vale missing-page design. Noindex directives remain in place for feedback, without implying privacy or access control. The sitemap is a route inventory; no search submission or indexing request is made.

This repository contains only publication-ready example assets, not private planning or company source documents. It does not establish production/client readiness, clinical approval, accessibility conformance, finalized service pricing or asset/trademark exclusivity.

To preview locally: `python3 -m http.server 7376 --bind 127.0.0.1`. GitHub Pages publishes the root of `main`; a push to that branch changes the public examples. Review intended public files before pushing. No custom domain or paid service is configured.
